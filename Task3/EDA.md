# Список проблем и рисков, которые связаны с планируемым ростом нагрузки на агрегатор

- В случае ошибок запроса агрегатора к одной из страховых компаний, запрашиваемый сервис не получит вообще никаких данных.
Для сервиса взаиморасчётов придётся ждать следующего дня если не предусмотрена система повторных запросов.

- Время ожидание ответа будет определятся временем ответа от самого медленного сервиса среди страховых компаний.
И на это время мы будет держать занятым подключение к сервису.

- Добавление новых страховых агентов только увеличит риск сбоев для внутренних сервисов. К тому же увеличится объем данных которые потребуется периодически выгружать агрегатору каждые 15 минут. Во столько же раз увеличится объем данных выгружаемые раз в сутки для сервиса взаиморасчетов. Этот размер может превысить  текущие лимиты на HTTP сообщения.

- Данное решение сложно масштабировать так как потребуется чем-то балансировать нагрузку на агрегатор.
